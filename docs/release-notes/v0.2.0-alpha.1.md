# SubBake 0.2.0-alpha.1

This is the first public preview of SubBake. Commands, configuration, and
persisted formats may still evolve before 1.0; breaking changes will be called
out in later release notes.

## Highlights

- Translate SRT, VTT, ASS/SSA, TTML/DFXP, and TXT files.
- Translate supported text or bitmap subtitle streams in media containers.
- Transcribe audio and video with a managed or external whisper.cpp installation.
- Run Economy, Turbo, or Cinema translation policies.
- Use the interactive terminal agent for planning, translation, transcription,
  safe subtitle editing, profile selection, session resume, and undo.
- Preserve deterministic subtitle IDs, formatting markers, glossary requirements,
  validation, cancellation, and resumable state.

## Download

The precompiled archive supports x86-64 GNU/Linux with glibc 2.35 or newer:

- `subbake-v0.2.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz`
- `SHA256SUMS`

Verify the archive before extracting it:

```bash
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf subbake-v0.2.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz
./subbake-v0.2.0-alpha.1-x86_64-unknown-linux-gnu/sbake --version
```

## Runtime dependencies

- Translation requires a configured model provider and API credential.
- Media inspection and conversion require `ffmpeg` and `ffprobe`.
- Agent `run_command` requires `bubblewrap` on Linux.
- Bitmap subtitle OCR requires Tesseract and the appropriate language data.
- Transcription requires whisper.cpp and a model; `sbake whisper install` and
  `sbake whisper model base` can install managed copies.

These external programs are not bundled in the SubBake archive.

## Compatibility notes

- Configuration version 2 is the first public configuration format.
- The pre-release `--fast` alias has been removed; use `--mode turbo`.
- Plan approval uses the interactive typed picker rather than `/approve` or `/reject`.
- Existing versioned runtime data remains readable where SubBake already provides
  a compatibility reader.

Windows and macOS remain experimental source-build targets, but this release does
not include precompiled assets for them.
